# Reusable Project Lessons

Read a note when its topic affects the work. These are historical lessons;
check current code before applying them.

- [2026-09-24] Cultivar social images: Next ImageResponse rejected WOFF2, and Satori ignored `inset` on absolute overlays. When changing social cards, use TTF or OTF fonts, set explicit overlay bounds, and inspect a generated PNG.
- [2026-07-19] AHS award labels: V2 AHS uses `L/W` for both the Lambert-Webster and Lenington All-American awards. When expanding award codes, keep the combined label or use the award URL to distinguish them.
- [2026-07-21] Cloudflare origin headers: A prior hostname-wide Cache Rule followed ordinary Next `Cache-Control` when no CDN-specific header was present. When excluding a public document, send an explicit CDN `no-store` directive and verify the result at the edge.
- [2026-07-17] Atlas lazy images: Waiting for `image.decode()` before scrolling can stall on lazy images the browser has not requested. When capturing a full page, traverse its geometry first, then wait for scoped visible images and check the final page height.
- [2026-07-16] Seeded Turso restores: A physical-order SQLite dump can leave mixed data after rejected inserts even when the Turso CLI exits successfully. When changing seed sync, preserve child-first drops, parent-first inserts, and post-sync table-count checks.
- [2026-06-18] R2 uploads: R2 rejected virtual-hosted S3 bucket requests in this project. When creating an R2 `S3Client`, use `forcePathStyle: true` and verify an upload against the intended endpoint.
- [2026-09-27] Atlas visual proof: A successful capture shows that the state was reached. When reviewing a UI change, inspect before and after images for clipping, overflow, missing content, and layout changes.
- [2026-09-27] Search candidate proof after index refactor: `mcp-real-sqlite-proof.test.ts` needs `.tmp/search/public-search-candidate.sqlite` with the current schema; the old index path does not satisfy cultivar search. After a search-index refactor, build the candidate from the sanitized local snapshot before the opt-in proof.
- [2026-09-27] Side-mutation manual Save: A list membership or image reorder action can write immediately and leave no parent form fields to send. When the user then clicks Save, the no-field branch must show success and close the editor without a redundant parent update.
- [2026-09-27] Member sync versions: Prisma relation-only list updates did not advance `List.updatedAt`, and automatic profile `@updatedAt` could repeat within one millisecond. When a member write feeds incremental dashboard sync or optimistic concurrency, advance the stored version atomically and prove the cursor with a real SQLite integration test.
- [2026-09-27] Profile story blur save: The story editor saves on an outside click, so its response can arrive while a member types in profile fields. When rebasing that response, do not reset the parent form if its visible field values are unchanged; a reset can drop characters during browser typing.
- [2026-09-27] List membership version rebase: Adding or removing a listing advances `List.updatedAt` even when the list title and description do not change. When the dashboard receives that version while a field draft is open, advance the form's version token if those stored fields are unchanged so Save does not reject the draft.
- [2026-09-27] Cultivar and listing-deletion versions: Prisma's automatic `updatedAt` can repeat within a millisecond, and assigning `Date.now()` can move a future-touched list version backward. When changing cultivar links or deleting a listing from lists, advance versions past their stored values and prove stale-write rejection and incremental sync with SQLite.
- [2026-09-29] Bounded member query plans: A LIMIT caps results, but a filter on a forced owner index can still scan the owner's full catalog. When changing member filters, inspect actual Prisma SQL plans and page through a fixed candidate window before primary-key hydration. List ID paging needs the composite owner/ID index to avoid sorting all owner rows.
- [2026-09-29] Profile conflict recovery: tRPC query utility fetch calls honor the app's 30-second stale time. When a member discards stale fields, use `staleTime: 0` to read the latest version. Detect mutation conflicts with the typed tRPC error code instead of server message text.
- [2026-09-28] Tailwind spacing units: This app's Tailwind spacing scale uses `0.25rem` per step. When cleaning arbitrary pixel utilities, do not treat equal values at a 16px root size as exact replacements. Preserve the unit and compare computed styles at enlarged root font sizes.
- [2026-09-28] Shadcn lint coverage: Adding a UI path to an ESLint ignores-only config hides it globally, even when a later config enables rules. When scoping existing rules away from shared primitives, keep ignores-only entries unchanged and verify that ESLint scans the primitive files.
- [2026-09-28] Sidebar cascade layers: Unlayered `:root` and `.dark` sidebar tokens won over later duplicates in `@layer utilities` because normal unlayered declarations have higher cascade priority. When editing theme tokens, check computed light, dark, and portal values before removing a duplicate block.
- [2026-09-29] shadcn workspace selection: The CLI reports the root component system unless `-c apps/main` is set, while this app uses Radix. When checking component APIs, run shadcn info and docs with `-c apps/main`.
- [2026-09-29] Atlas seed isolation: `personas.json` has an absolute database path, and `pnpm env:dev` can pass a separate `DATABASE_URL` into Atlas. When comparing visual states in an independent checkout, point the manifest at that checkout's seed and unset database env values so Atlas uses a disposable snapshot.
- [2026-09-29] Alert dialog action colors: `AlertDialogAction asChild` forwards default button classes to its child, which can override a destructive Button. When an action deletes data, set `variant="destructive"` on `AlertDialogAction` and check its computed color.
- [2026-09-29] Numeric Escape in dialogs: Radix listens for Escape on document in the capture phase. An input's bubble handler cannot prevent dialog dismissal by itself. When Escape must restore a numeric draft, prevent dismissal in `DialogContent.onEscapeKeyDown`, then restore the field in its key handler. Test Escape from the field and from another dialog control.
- [2026-09-29] GitHub tall images: GitHub capped a dimensioned HTML contact sheet at 2000px high. Plain Markdown removed that cap and filled the PR content width. When publishing one tall evidence sheet, omit image dimensions, add a full-size link, and measure the rendered image in GitHub.
- [2026-09-29] Sheet stepper clicks: Blur can change preview geometry and scroll position between pointerdown and pointerup, so the stepper never receives click. When a numeric step must use the current draft, keep input focus during pointerdown, commit the step on click, then focus the button. Verify the real browser event sequence and keyboard activation.
- [2026-09-29] Preview E2E identity: A preview alias can return an older site's home page before the alias job assigns the deployment. Run preview E2E against the deployment event's immutable URL. When checking a run, verify its checkout SHA and BASE_URL in the job log; run head metadata can name a different commit.
- [2026-09-29] Dashboard cultivar links: Public listings and the listing editor use `AhsListingDisplay`, but each caller must pass `cultivarHref`. Build the editor URL from the linked cultivar reference's `normalizedName`, not the seller's editable listing title.
- [2026-09-29] Cold lint integration: The first ESLint text check loads the project's TypeScript and Tailwind config and exceeded the default 15-second test limit locally. When checking design rules, allow 60 seconds for that first integration call. Keep the rule assertions unchanged.
- [2026-09-29] Remote photo crop boundary: The dashboard cropper makes a square WebP with a 1,600-pixel output limit before upload. Remote MCP stores the supplied bytes; shared R2 variants run after attachment. When changing remote photo tools, verify crop and original-size rules separately from moderation and variant generation.
- [2026-09-29] Cropper image bounds: ReactCrop uses its wrapper size for percentage selection coordinates. A forced full-width block can make portrait selections wider than the image. Keep the library's inline-block layout, crop from natural image coordinates, and test portrait and landscape bounds after a viewport change.
- [2026-09-29] Browser tRPC response mocks: The browser upload mutation uses the batch stream link and expects JSON Lines, even when only one call is sent. When intercepting that response in Playwright, use the installed tRPC jsonlStreamProducer with the app's SuperJSON transformer; a plain JSON batch fails before upload.

- [2026-09-30] MCP video and dashboard cache: The open dashboard can keep its persisted image order after a remote MCP reorder. When recording or checking remote writes, use the visible Refresh dashboard data control and verify image IDs in display order. Wait for browser WebMCP tool registration after page loading before executing a tool.
- [2026-09-29] Scrolled screenshot crops: A browser screenshot crop did not match viewport coordinates after scrolling. For PR evidence, capture the viewport with `getScreenshot`, crop the saved file, and inspect that exact file before upload. A live screenshot does not verify the saved attachment.
- [2026-09-29] Browser screencast capture: Read the CDP event cursor before starting a screencast, then read and acknowledge frames inside active browser tool calls. A background capture loop across tool calls can stop after one frame. Save the real frames and trim idle time when making feature videos.
- [2026-09-29] Bulk cultivar matcher cost: `includeCandidates: true` runs fuzzy candidate queries for each unmatched name. Use `false` when the caller only uses `exactMatch`. Keep candidate lookup for the explicit Find cultivar action.
- [2026-09-29] Public query hooks: The public shell has no QueryClientProvider. Installed TanStack `useQuery` accepts a QueryClient as its second argument. Pass the existing `getQueryClient()` for a public client feature instead of adding auth providers to the public layout. Disable automatic refetches when restoring browser-only lists.

- [2026-09-29] Cultivar autocomplete: Use `/api/v1/cultivars/search` with `mode=summary`, `cultivarName`, and a small `limit` for partial names. Summary mode enables the last-token prefix, skips listing and parentage-tree expansion, and uses the public Cloudflare cache policy. The importer matcher is for exact or fuzzy full names. Enable the existing public-search runtime flag on an isolated local server when testing autocomplete.
- [2026-09-29] Listings menu return focus: Radix can open a menu on pointer-down without a click on its trigger. Track pointer-down and keyboard focus on the dashboard. Keep table column callbacks stable during URL changes so the saved trigger stays connected. Check return focus and scroll through the browser.
- [2026-09-29] Realistic media fixture: The current seeded 18-33 listing has one image; the older listing-media Atlas case expects nine. For matched reference captures, add image records only to a disposable snapshot. Do not change product assertions to hide a fixture mismatch.
- [2026-09-29] Catalog preview grid: CatalogListingGrid uses one column below sm, two at sm, and three at lg by default. The old importer Atlas mobile check expected two columns at 402px. Use the shared grid definition for viewport checks.
- [2026-09-29] Public range readiness: Public catalog search loads listings in pages. Range bounds can change until all pages load. For browser range checks, wait for the unfiltered page count to match the displayed total and for the loading indicator to close.
- [2026-09-29] Row action test clicks: Success toasts can cover the right-side row menu button. A forced click skips the receiving-events check and hits the toast. Use a normal Playwright click so it waits for the button to receive input.
- [2026-09-29] Editor URL ownership: Optimistic editor closing exposes the table before the editing URL clears. A table URL update can retain the old editor ID. Use the committed editing query value to control the surface. Check Back followed by an immediate table action.

- [2026-09-29] Sonner hover and row actions: Sonner pauses notification dismissal on hover. A notification can cover a table row button after Save. A Playwright click can keep the pointer over that notification and wait until test timeout. Before a row action in browser tests, hover the Listings heading, check that notification hover state clears, and wait for notifications to close. Moving to viewport coordinate 0,0 did not clear that state in the failed trace. Keep normal click actionability checks.

- [2026-10-01] WebMCP registration: The current WebMCP specification uses document.modelContext and asynchronous registerTool calls. Abort the registration signal to remove page tools. For component tools, use the shared registration helper. Keep tool registration stable during crop changes and check cleanup without resetting the dashboard tool set.

- [2026-10-01] Removal review lifetime: The selected-items action bar unmounts when selection or filtering leaves no visible selected rows. Keep automatic review consumption in the list-table parent, keyed by the list and removal intent. Check Cancel followed by deselection, filtering, reselection, and an explicit Remove action.

- [2026-10-01] Integration list isolation: The full-app integration runner shares one disposable database across test files. Earlier create/edit tests add a listing to Integration Favorites. For a test that needs an exact membership count, create its own list through the UI. Do not rely on the shared fixture staying empty.
